# CheckPoint 2 – Atores e Atrizes

App em HTML, CSS e JavaScript que exibe atores e atrizes em cards (foto, nome, país e data de nascimento) e filtra pelo nome enquanto o usuário digita (`oninput`, `filter()` e `includes()`).

## Como rodar
Abra o `index.html` no navegador.

## Arquivos
- `index.html` – estrutura da página
- `style.css` – estilos
- `script.js` – renderização e filtro
- `dados.js` – array `atores` (fornecido)
